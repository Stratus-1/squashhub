# Comms / AGM rules
- AGM nominations precede the secret ballot on the same draft: hashed personal links, eligible-only name search, self-nominations auto-accepted only when the ballot's admin-set `allow_self_actions` is on (off = self-nominations rejected and the voter's own name hidden on their ballot), others need acceptance; at close accepted nominees become candidates and positions lock; why: ballots list only consenting eligible nominees.
