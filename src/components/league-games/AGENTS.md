# League games rules
- League fixture entry distinguishes partial saved scores from final submitted scorecards; only past/final results use correction mode, because ongoing court scoring must stay accessible after each rubber finishes.
- League fixtures split Set up (captains, admins, lineup players, league permission) from Mark game (`?mode=mark`, any signed-in club member or open Court QR device); mark mode hides lineup/format editing and waits for setup. Why: anyone can score, only responsible people pick lineups.
