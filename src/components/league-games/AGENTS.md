# League games rules
- League fixture entry distinguishes partial saved scores from final submitted scorecards; only past/final results use correction mode, because ongoing court scoring must stay accessible after each rubber finishes.
- League fixtures split Set up (captains, admins, lineup players, league permission) from Mark game (`?mode=mark`, any signed-in club member or open Court QR device); mark mode hides lineup/format editing and waits for setup. Why: anyone can score, only responsible people pick lineups.
- Re-opening submitted/past league scorecards ("Edit Submitted Scores") is allowed via `canEditSubmittedLeagueScores` in `src/lib/leagues/fixture-setup-access.ts`: club admins, NSA captains and Leagues-permission holders for their own club's fixtures; the same rule gates the Standings grid edit pencil, original-player bonus adjustments, recalculated-points saves, the final-score shortcut, overdue-result submission, recorded-player corrections (`admin_correct_rubber_participant` accepts the club's Leagues permission) and ladder preview; applying ladder moves still needs the Ladder permission server-side. Why: league organisers must fix score mistakes without full admin rights.
