# Match Day rules

- Match Day Access is an authorisation alternative, not a second UI: one persistent token per competition in `match_day_access` (court/match = URL suffix); `/md/*` renders the existing League Games screens inside `MatchDayDeviceContext`, sending REST requests as anon + `x-match-day-token` (`src/lib/match-day/device.ts`), and anon `md_hdr_*` RLS policies scope reads/writes to that season's open fixtures (names-only member columns, submit only with both captain signatures), audited as 'Match Day Access'; tournament links render the same Tournaments / ClubChampsView / MatchMarker / TournamentMatchLive screens (paths mapped by `useMdNavigate`, the RLS-bypassing `club_champs` view swapped for the filtered `md_club_champs`, score-only update guard trigger, `save_marker_match_result` device branch); why: one scoring engine, no admin/member exposure, tokens never minted per email.
